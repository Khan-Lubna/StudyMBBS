# StudyMBBS
Project Overview:
This is a fully responsive landing page for students interested in studying MBBS abroad. It includes country listings, program details, an admission guide, and a lead generation form to collect user information.
🔹 Live Demo: https://studymbbs.netlify.app/
🔹 GitHub Repository: https://github.com/Khan-Lubna/StudyMBBS 
Features:
🔹 Responsive design with Tailwind CSS
🔹Hero Section with an eye-catching CTA
🔹Top MBBS Destinations (Russia, Uzbekistan, Kazakhstan, etc.)
🔹Step-by-step Admission Guide & Eligibility Criteria 
🔹Lead Generation Form (Name, Email, Phone, Country Preference)
🔹Form Validation using JavaScript
🔹SEO Optimization (Meta Tags, Alt Attributes, Structured Data)
🔹Google Analytics & Facebook Pixel integration
🔹Fast Loading & Mobile Friendly
Tech Stack:
🔹Frontend: HTML, Tailwind CSS, JavaScript
🔹SEO Optimization: Meta tags, alt attributes, structured data
